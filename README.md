# 🃏 德州筹码 (Chips Betting)

多人实时德州扑克筹码下注 H5 应用 —— 基于 WebSocket 的实时多人筹码对赌系统。

## ✨ 功能特性

### 核心玩法
- **实时多人对赌**：WebSocket 长连接，多玩家同时在线下注，状态实时同步
- **底池机制**：所有玩家投入的筹码汇入中央底池，收池赢家通吃
- **下注/跟注/弃牌/收回**：完整的德州扑克动作轮
  - 下注：将筹码投入底池
  - 跟注（Call）：自动补齐到当前最高下注额，余额不足则 All-in
  - 弃牌（Fold）：退出本轮，投入的筹码留在池中
  - 收回：拿回自己本轮投入的筹码（仅限未结算时）
- **收池结算**：赢家一键收池，全房间弹窗展示每位玩家本轮净输赢

### 动态下注面板
- **底池 < 10**：显示固定金额快捷按钮（1 / 2 / 5 / 12 / 50 / 100 / 全押）
- **底池 ≥ 10**：自动切换百分比模式（20% / 33% / 50% / 75% / 100% / 全押），按钮下方显示对应金额
- 自定义金额输入框，回车即下注

### 视觉体验
- **3D 筹码堆叠**：底池筹码以圆柱渐变立体堆叠展示，最多 3 堆（白/红/蓝三色面额），堆高随金额增长
- **牌桌下注标签**：每位下注玩家在底池区显示头像 + 投入额，弃牌/离线状态有视觉区分
- **收池弹窗**：全屏遮罩 + 弹跳动画，展示赢家及所有玩家净输赢明细
- **连接状态指示**：顶栏绿点/红点实时反映 WebSocket 连接状态
- **断线自动重连**：指数退避重连策略，重连遮罩提示进度

### 持久化与账号
- **状态持久化**：服务器通过 `state.json` 保存玩家余额、总输赢、底池历史，重启不丢数据
- **玩家身份**：基于 `localStorage` 存储 Player ID，刷新/重连自动恢复身份和余额
- **昵称修改**：随时改名，全房间同步
- **庄家补筹码**：支持给玩家手动加筹码（上限 10000）

## 🛠 技术栈

| 层 | 技术 |
|---|---|
| 后端 | Node.js + Express + ws (WebSocket) |
| 前端 | 纯 HTML/CSS/JS（单文件，零依赖） |
| 持久化 | 文件系统（`state.json`） |
| 通信协议 | WebSocket JSON 消息 |

## 🚀 快速开始

```bash
# 安装依赖
npm install

# 启动服务（默认端口 3002）
npm start

# 或指定端口
PORT=8080 npm start
```

浏览器打开 `http://localhost:3002` 即可进入房间。

## 📡 WebSocket 消息协议

| 客户端 → 服务端 | 说明 |
|---|---|
| `join` | 加入房间（携带昵称 + 已存 playerId 用于恢复身份） |
| `rename` | 修改昵称 |
| `bet` | 下注（amount 为投入金额） |
| `call` | 跟注（自动补齐到最高下注） |
| `fold` | 弃牌 |
| `collect` | 收回本轮已投入的筹码 |
| `winPot` | 收池（赢家通吃底池） |
| `addChips` | 庄家补筹码 |

| 服务端 → 客户端 | 说明 |
|---|---|
| `joined` | 确认加入，返回玩家信息 + 底池状态 |
| `state` | 全量房间状态（底池 + 所有玩家） |
| `bet` | 下注广播 |
| `collect` | 收回广播 |
| `fold` | 弃牌广播 |
| `winPot` | 收池结算广播（含每人净输赢） |
| `playerJoined` / `playerLeft` | 玩家进出房间通知 |
| `renamed` | 改名通知 |
| `error` | 错误提示 |
